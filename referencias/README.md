# Referências do CHEMAQ

Esta pasta guarda, em texto curto, tudo o que a Divisão de Máquinas consulta com frequência: dispensas já publicadas, manuais dos motores, códigos CATMAT/CATSER e dados do navio. A ideia é ler primeiro o resumo em Markdown e só abrir o PDF original quando faltar algum detalhe.

## Como usar

1. Procure o assunto no índice abaixo.
2. Leia o resumo (`.md`). Cada resumo traz os dados-chave, a estrutura do documento e os textos-padrão que podem ser reaproveitados.
3. Se precisar do texto exato ou de uma tabela, abra o PDF na subpasta `pdf/` do mesmo item.

Regras da pasta:

- Um resumo por documento, com no máximo algumas páginas.
- Nada de telefone, e-mail, matrícula/SIAPE, NIP ou CPF nos resumos nem nos PDFs (o repositório é público). O DFD foi guardado com esses campos tarjados.
- Ao acrescentar um item novo, inclua uma linha no índice abaixo.
